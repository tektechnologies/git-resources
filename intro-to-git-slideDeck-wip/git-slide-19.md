## Go To Your Projects Folder

- Open or switch back to command line (Terminal or Git Bash)

- Type **`pwd`**
  - Print Working Directory
  - It should show something like `.../Desktop/Projects`
  - If not, type `cd ~/Desktop/Projects`

- Type **`ls`** to list directory contents

The terminal example shows:

```bash
Keith@K MINGW64 ~/Desktop/Projects
$ pwd
/c/Users/Keith/Desktop/Projects

Keith@K MINGW64 ~/Desktop/Projects
$ ls
code101/

Keith@K MINGW64 ~/Desktop/Projects
$
