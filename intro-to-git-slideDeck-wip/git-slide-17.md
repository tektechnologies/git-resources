# What's A Repository?

A repository is a collection of files.

- Usually, one project = one repository.
- Really large projects might have multiple repositories for different parts of their system (e.g. front end and back end).
- Repositories can live on GitHub or your computer.
- Now we need to make a copy of this repo on our computers.
- Repos can be connected, allowing them to send code to and receive code from each other.
- We'll do this by **cloning**.
