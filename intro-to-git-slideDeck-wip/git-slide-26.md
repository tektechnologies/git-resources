# Git Cheat Sheet

## Navigating the Terminal

**`cd folder-name`**
Type `cd folder-name` to navigate to a folder.¹ Type `cd ..` to go to the parent folder.

**`ls -la`**
Display ALL (including hidden) files in the folder. `-la` is a flag. Flags modify commands.²

## Using Git

**`git clone url`**
Replace `url` with the url of a repo you want to clone to your computer.

---

¹ Start typing the folder name and hit tab to auto-complete.

² Flag letters are abbreviations. `l` stands for list and `a` stands for all. You can mix and match these freely. Try `ls`, `ls -a`, and `ls -l` to see the differences.
